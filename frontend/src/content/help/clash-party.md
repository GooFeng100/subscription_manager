# Clash Party 使用说明

本节以 Clash Party 客户端为例，说明如何导入订阅并选择节点。

## 下载与安装

请先从 Clash Verge Rev 官方文档获取最新版本并完成安装。
:::info
:icon[Windows](/help-assets/windows.png) Windows（不再支持 Win7）
:icon[macOS](/help-assets/macos.png) macOS
:::

## 导入订阅链接

1. 打开 Clash Party。
2. 进入订阅管理页面。
3. 粘贴从网站复制的订阅链接。
4. 点击导入。

![导入订阅链接](/help-assets/08-clash-party-import.png)

导入成功后，可以在客户端中看到新的订阅配置文件。

![订阅导入成功](/help-assets/09-clash-party-imported.png)

## 更新订阅

如果节点列表没有显示，或需要同步最新节点，可以点击更新按钮。

![更新订阅](/help-assets/10-clash-party-refresh.png)

## 选择导入的订阅文件

在客户端中选择刚刚导入的订阅配置文件。

![选择订阅文件](/help-assets/11-clash-party-selected-profile.png)

## 选择代理组和节点

进入代理组页面，在需要的代理组中选择节点。

![选择代理组](/help-assets/12-proxy-group-select.png)

![代理组列表](/help-assets/13-proxy-groups.png)

## 选择合适节点

可以按地区、延迟、使用场景选择合适节点。

![节点列表](/help-assets/14-node-list.png)
