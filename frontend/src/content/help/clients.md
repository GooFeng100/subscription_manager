# 客户端推荐

不同设备可以选择不同客户端。

## Windows

建议使用：

- Clash Verge
- Clash Party
- Mihomo Party

## macOS

建议使用：

- Clash Verge
- Surge

## iPhone / iPad

可选客户端：

- Shadowrocket
- Surge
- Stash
- Clash Mi

注意：Shadowrocket 通常需要登录外区 Apple ID 后在 App Store 下载。

苹果手机端如果使用 Shadowrocket，通常直接选择节点即可。若需要更好的智能分流体验，建议选择支持 Clash 订阅的客户端。

## Android / HarmonyOS

建议使用：

- ClashMetaForAndroid
- Surfboard

## 下载说明

部分客户端无法在国内应用商城直接下载，需要自行从官网、GitHub 或对应应用商店获取。

> 后续可补充：各客户端官方下载地址、安装教程、导入截图。
