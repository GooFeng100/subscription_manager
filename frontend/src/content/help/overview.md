# 系统介绍

本文档用于说明如何注册账号、兑换授权码、获取订阅链接，并把订阅导入客户端使用。

## 访问地址

网站地址：`https://sub.889100.xyz`

## 使用流程

1. 打开网站并注册账号。
2. 登录后进入「我的订阅」。
3. 如果账号显示「未授权」，进入「兑换」页面输入授权码完成激活。
4. 回到「订阅」页面，选择客户端模板并复制订阅链接。
5. 在对应客户端中导入订阅链接，选择节点并开启系统代理。

## 适用客户端

当前页面支持常见客户端模板，例如 Clash、Surge、Quantumult X、Shadowrocket、Surfboard、Loon 等。实际可用客户端以页面显示为准。
