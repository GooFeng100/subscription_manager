# 授权码兑换

首次注册登录后，账号可能处于「未授权」状态。未授权账号无法正常使用订阅，需要先兑换授权码。

![未授权状态](/help-assets/03-dashboard-inactive.png)

## 进入兑换页面

在底部导航中点击「兑换」。

![进入兑换页面](/help-assets/04-redeem-entry.png)

## 输入授权码

在「兑换授权码」页面输入获得的授权码，然后点击「立即兑换」。

![输入授权码](/help-assets/05-redeem-code.png)

## 兑换成功后

兑换成功后，账号状态会变为正常，并显示到期日期。

![授权后账户信息](/help-assets/06-dashboard-active.png)

:::warning
- 授权码只能使用一次。
- 授权码请勿泄露给他人。
- 如果提示授权码无效、已使用或已作废，请联系售后确认。
- 有效期显示以页面展示为准。
:::
