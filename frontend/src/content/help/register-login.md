# 注册与登录

## 打开网站

访问：`https://sub.889100.xyz`

## 登录已有账号

在登录页输入用户名和密码，完成验证后点击「登录」。

![登录页面](/help-assets/01-login.png)

## 注册新账号

如果没有账号，点击登录页下方的「立即注册」，进入创建账号页面。

注册时需要填写：

1. 用户名
2. 密码
3. 确认密码
4. Cloudflare 人机验证

:::info
用户名规则：英文字母开头，英文字母 + 数字组合，至少 8 位。  
密码规则：至少 8 位。  
填写完成后点击「注册」。
:::

:::tip
建议先把用户名和密码准备好，再开始填写注册表单，这样可以减少来回修改。
:::

:::warning
请不要使用过于简单的密码，也不要把账号信息发送给他人。
:::

![注册页面](/help-assets/02-register.png)

## 返回控制台

注册完成后，回到登录页输入账号密码，登录后进入控制台。
